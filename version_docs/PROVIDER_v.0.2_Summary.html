4 classes → 9 named AgentLists

Farmer

  • role="sa" → SA Farmers (×2)
  • role="eu" → EU Farmers (×3)

SA produces soja; EU consumes feed and produces livestock output.

Trader

  • role="wholesaler" → Wholesalers (×2)
  • role="feed_trader" → Feed Traders (×2)

Pure intermediary — buys from upstream, sells to downstream, no transformation.

Transport

  • role="sa_land" → SA Land (×1)
  • role="sea" → Sea Transport (×1)
  • role="eu_land" → EU Land (×1)

Capacity-constrained; passes commodity price through + freight fee.

Process

  • role="processor" → Processors (×2)
  • role="feed_manufacturer" → Feed Mfg. (×2)

Converts commodity; Processor applies 0.8 yield ratio (20% soja lost as waste).

Every agent computes its own unit_price at the end of its step using a cost-plus rule: cover your fixed costs per unit sold, then add your profit margin on top. Prices cascade downstream — each agent's output price becomes the next agent's input cost.

SA Farmer

Step 1  ·  Farmer(role="sa")
# Drought reduces yield → raises unit cost qty = base_yield × (1 − drought_severity) unit_price = (fixed_costs / qty) × (1 + margin)

e.g. fixed_costs=36000, qty=100t, margin=0.10 → price=396 €/t

Wholesaler / Feed Trader

Steps 2 & 8  ·  Trader
# Buy from upstream (equal share across peers) stock = total_upstream_qty / n_active_peers avg_buy_price = weighted_avg(upstream prices) unit_price = (avg_buy_price + fixed_costs / stock) × (1 + margin)

Pass-through: carries upstream commodity cost + own overhead per unit.

Transport (all three roles)

Steps 3–5  ·  Transport
# Freight fee on top of commodity price qty_moved = min(upstream_share, capacity) upstream_price = weighted_avg(upstream prices) freight_fee = (fixed_costs / qty_moved) × (1 + margin_transport) unit_price = upstream_price + freight_fee

Transport is a SERVICE. The soja price passes through; the freight fee is added on top.

Processor

Step 6  ·  Process(role="processor")
# Yield loss: 1 tonne soja → 0.8 tonne meal ratio = 0.8 qty_out = input_received × ratio # Need 1/ratio input units to produce 1 output unit input_cost_per_output = avg_input_price / ratio unit_price = (input_cost_per_output + fixed_costs / qty_out) × (1 + margin)

The 20% loss is priced in: it costs more input to produce each unit of output.

Feed Manufacturer

Step 7  ·  Process(role="feed_manufacturer")
# ratio=1.0 — no yield loss in compounding ratio = 1.0 qty_out = input_received × ratio unit_price = (avg_input_price / ratio + fixed_costs / qty_out) × (1 + margin)

Same formula as Processor, just ratio=1.0 so no input-cost amplification.

EU Farmer (end consumer)

Step 9  ·  Farmer(role="eu")
# Receives equal share of all feed trader output total_feed = sum(feed_trader.qty_available) feed_received = total_feed / n_active_eu_farmers # Livestock output scales with feed received livestock_output = feed_received # Bankruptcy if no feed for 3 steps in a row if steps_without_input ≥ 3: active = False

EU farmers are pure consumers; they don't set a price, they set livestock_output.

Price Propagation Example (no drought)
SA Farmer    →   396 €/t soja    +  Wholesaler overhead    →   ~490 €/t    +  SA Land freight    →   ~500 €/t    +  Sea freight    →   ~555 €/t    +  EU Land freight    →   ~563 €/t    ×  Processor (÷0.8)    →   ~800 €/t meal    +  Feed Mfg. overhead    →   ~1000 €/t feed    +  Feed Trader overhead    →   ~1200 €/t delivered feed

These are approximate illustrations. The big jump at the Processor comes from the 0.8 conversion ratio: you need 1.25 tonnes of raw soja to produce 1 tonne of meal, so the input cost per output unit jumps by 25%.

Task 1 — Two-Phase Initialisation (why it's needed)
Melodie's AgentList.setup_agents(n) creates agents and calls agent.setup() internally — before any parameters are applied. That means the role is not known yet when setup() runs. Solution:

Phase 1 — setup(): zero-initialise every field so Melodie can serialise/record the agent safely.
Phase 2 — post_setup(): model sets agent.role, then calls agent.post_setup() for role-specific initialisation (reads scenario params, sets capacity, computes initial price).

Key Design Rule: Equal-Split Deterministic Flow
There is no bidding, no market clearing, and no price negotiation in this first implementation. Every agent simply takes total upstream output ÷ number of active peers.
Example: 2 SA Farmers produce 100 t each (total 200 t). 2 Wholesalers are active → each Wholesaler gets 100 t.

This keeps the simulation fully deterministic and easy to trace. The equal-split can later be replaced with a proper market mechanism (bidding, capacity constraints, contracts) once the base flow is validated.
