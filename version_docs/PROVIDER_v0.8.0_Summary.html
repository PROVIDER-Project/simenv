What works end-to-end

All four supply routes (BRA/STO, BRA/PRG, ARG direct, USA direct) are active and quantity-routed through the chain. PDL supply/price shocks for all six mapped entity types propagate correctly. Both SA port capacities receive independent shocks from the same PDL file.
